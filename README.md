This project allows users to view news articles from different sources all in one place. Collaborated by a team of 4 NJIT members, we delegated tasks to effectively use Linux, javascript, css, html, and PHP to allow users to:
. create and register profiles, sending successful email upon registration
. view articles
. save articles
. share articles with other users
. rate articles

Full work is completed on WebZone-1 Branch
